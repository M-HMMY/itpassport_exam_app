## 書き方の注意

- 本文は TypeScript のテンプレートリテラル内に入ります。バックスラッシュは 2 つ重ね、バックティックはエスケープが必要です
- **bash のヒアドキュメントはバックスラッシュを落とすので使わないこと。** ファイルを直接書くか、`scripts/emit_textbook.py`（Markdown を Python の raw 文字列で書いて .ts に変換する小道具）を使ってください
- 図（三連バッククォート + `diagram:flow` / `stack` / `compare` / `tree` / `cycle` / `seq`）を積極的に使ってください。**五大装置は `flow`、記憶階層は `stack`、直列と並列の稼働率は `compare` が向いています**
- `compare` は「1 行 1 セル、偶数行が左・奇数行が右」で書きます。**要素が奇数個だと検査でエラーになります**
- 図の中では `**強調**` が効きません。書かないでください
- 数式は `$...$`（行内）と 三連バッククォート + `math`（別行立て）が使えます。稼働率の式はこれで書くと読みやすくなります。使える記号は `src/lib/mathSymbols.ts` にあります
- 節からのリンクは `[文字](textbook/t-sys-2)` の形。**存在するのは `i-1`〜`i-4`、`s-corp-1`〜`s-corp-5`、`m-dev-1`〜`m-dev-3`、`m-pm-1`〜`m-pm-2`、`m-sm-1`〜`m-sm-3`、`t-basic-1`〜`t-basic-4`、`t-algo-1`〜`t-algo-3`、そして今回書く `t-comp-1`〜`t-comp-3`・`t-sys-1`〜`t-sys-3` だけ**です。それ以外へはリンクしないこと（`t-sec-*` と `t-nw-*` は別の人が同時に書いているので、リンクしないでください）

## 事実の扱い

**確信のない事実は書かないでください。** 特に間違えやすい箇所：

- RAM は電源を切ると消える（揮発性）、ROM は消えない（不揮発性）
- キャッシュメモリは主記憶より高速・小容量で、CPU と主記憶の速度差を埋めるもの
- MTBF は平均故障間隔（動いている時間）、MTTR は平均修復時間（直すのにかかる時間）。稼働率 = MTBF ÷ (MTBF + MTTR)
- 直列（両方必要）の稼働率は掛け算、並列（どちらか動けばよい）は $1-(1-a)(1-b)$
- デュアルシステムは 2 系統で同じ処理をして結果を照合、デュプレックスシステムは主系と待機系
- SaaS はソフトウェア、PaaS は開発環境、IaaS はインフラ（ハードウェア相当）を借りる
- フェールセーフは「安全な側に倒れる」、フールプルーフは「誤操作をそもそもさせない」。この 2 つの取り違えは頻出
