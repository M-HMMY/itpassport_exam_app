## 読者像（最重要）

**IT の知識がゼロで、多くは数学にも苦手意識のある人**です。学生・事務職・営業職。

- 専門用語は初出のその場で必ず言い換える。「後で説明します」は禁止
- **計算は必ず「なぜその式になるか」から入る。** 公式の暗記を求めない
- 2 進数は「使える記号が 0 と 1 の 2 つしかないだけで、桁が増える仕組みは普段の数え方と同じ」という説明から始める
- 1 文を短く
- カタカナ語・アルファベットの略語には、元の英語とその意味を添える

**この 2 章は、読者が最も身構える場所です。** 「難しくない」と言うだけでなく、実際に手順を追えば必ず答えが出ることを、具体例で示してください。

## 書き方の注意

- 本文は TypeScript のテンプレートリテラル内に入ります。バックスラッシュは 2 つ重ね、バックティックはエスケープが必要です
- **bash のヒアドキュメントはバックスラッシュを落とすので使わないこと。** ファイルを直接書くか、`scripts/emit_textbook.py`（Markdown を Python の raw 文字列で書いて .ts に変換する小道具）を使ってください
- 図（三連バッククォート + `diagram:flow` / `stack` / `compare` / `tree` / `bits` / `cycle`）を積極的に使ってください。2 進数の桁の重み、スタックとキュー、探索の動きは図が効きます。`bits` はビット列を並べる図です
- `compare` は「1 行 1 セル、偶数行が左・奇数行が右」で書きます。**要素が奇数個だと検査でエラーになります**
- 図の中では `**強調**` が効きません。書かないでください
- 数式は `$...$`（行内）と 三連バッククォート + `math`（別行立て）が使えますが、**この試験では出番が少ない**ので、式で書いた方が分かりやすいときだけにしてください。使える記号は `src/lib/mathSymbols.ts` にあります
- 節からのリンクは `[文字](textbook/t-basic-3)` の形。**存在するのは上の表の 7 つの id だけ**なので、それ以外へはリンクしないこと。ページへのリンクは `[直前チェックシート](sheet)` `[確認問題](practice)` `[計算ドリル](drill)` が使えます

## 事実の扱い

**確信のない事実は書かないでください。** 特に注意する箇所：
- 記憶容量の K は文脈により 1000 と 1024 の両方があること（試験では問題文の指定に従う）
- 中央値と平均値の違い、外れ値に強いのはどちらか
- コンパイラは実行前にまとめて翻訳、インタプリタは実行しながら 1 行ずつ
- スタックは後入れ先出し（LIFO）、キューは先入れ先出し（FIFO）
